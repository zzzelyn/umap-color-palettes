UMAP 科研配色卡

点击色块 / HEX 复制单色，点按钮复制整组向量（R / Python）

使用说明：
① 点击任意色块或下方的 HEX 标签即可复制该颜色；点「复制 R 向量 / 复制 Python 向量」可整组复制，直接粘进 Seurat / Scanpy 使用。
② 画细胞类型用离散多色（一色对应一类细胞），画基因表达 / score 用连续渐变色——两套色板请不要混用。
③ 配色按用途分四类：单色渐变（基因表达）、冷暖双色发散（score / 上·下调）、彩虹渐变（拟时序），以及细胞类型分类（离散多色）。
